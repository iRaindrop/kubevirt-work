# kubevirt-work

This repository mirrors the files for an AI assisted analysis, currently for KubeVirt. All files are under the `.github` folder so that all the analysis work is confined in a clone of repository being analyzed.

Read the .github/copilot-instructions.md file, that describes the analysis process. The "Analysis Criteria and Predefined Prompts" describes the layout of the files.
